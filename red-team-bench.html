MOM Red-Team Bench tests two standard audio-classification baselines on recordings held out by source, then challenges them with controlled signal changes. It reports missed target events and false positives separately—because one overall score is not the whole story.

01 / Run locally

Build a report from your labeled clips

The Python benchmark reads audio and trains models on your computer. This page only visualizes the resulting JSON.
Start with the benchmark instructions
You need one row per labeled clip and a recording_id that groups clips from the same source.
Read setup guide ↗
Command: python mom_redteam_bench.py --manifest path/to/manifest.csv --out mom_redteam_report
Do not upload private or identifiable health recordings to a website. Keep data local and use only recordings you are authorized to analyze. The report is only as trustworthy as the labels and recording-level split.
