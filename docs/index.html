Why frequency-domain analysis?

Amplitude can rise because of target acoustic activity, motion, contact changes, or environmental noise. The analysis therefore examines spectral composition rather than assuming that every large-amplitude event is biologically meaningful.

The public analysis computes the fraction of 20–2,000 Hz spectral power that lies inside 120–480 Hz after mean-centering, Hann tapering, and an FFT.

Reproducible analysis methodology

The public repository is structured so a reviewer can recompute the reported analysis rather than trust a screenshot or manually entered table.

Acquire the immutable source filesThe script downloads the seven Figshare v1 WAV files and seven matching annotation files.
Standardize audioAudio is converted to floating point, mean-centered, and 48 kHz recordings are resampled to 8 kHz.
Create fixed analysis windowsEach recording is divided into non-overlapping 500 ms windows, corresponding to 4,000 samples at 8 kHz.
Apply annotation rulesSB, MB, CRS, and HS annotations define confirmed bowel-sound events. Ambiguous or boundary-adjacent windows are excluded by explicit rules.
Calculate the primary spectral featureAfter a Hann taper and real FFT, the script computes power(120–480 Hz) / power(20–2,000 Hz).
Respect the data hierarchyWindow-level distributions are descriptive. Higher-level comparisons use four filename-date groups as unverified grouping units, not verified participant IDs.
Run the verification gatepython process_gut_audio.py --download --verify independently recomputes the outputs and checks them against reported values.

Limitations and scope

Research prototype, not a medical device. This work does not establish diagnostic accuracy, gastrointestinal motility measurement, or clinical safety/effectiveness. The public repository reproduces a secondary spectral analysis of an existing acoustic dataset and explicitly does not validate the ESP32/MAX4466 hardware.

Independent-unit limitation

The public release does not provide a verified mapping from the seven recordings to participant identities. Four filename-date prefixes are therefore treated only as unverified higher-level grouping units.

Prototype limitation

Consumer-grade microphones and mechanical coupling are sensitive to placement, motion, contact pressure, gain, and room noise. Hardware performance should be validated separately from the public spectral-analysis result.
