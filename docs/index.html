MOM records abdominal sounds and learns how they relate to your own hunger check-ins.

Hold the stethoscope-style sensor against the documented abdominal position, record for one minute, and rate how hungry you feel. Over time, MOM tests whether repeatable patterns appear for that individual.

POWER

After one firmware flash, Arduino is not part of normal use.

Disconnect the ESP32 from the programming computer. Plug it into a stable USB power bank and the saved firmware starts automatically. For remote transfer, it connects to a saved 2.4 GHz Wi‑Fi network or phone hotspot.

SAFETY & LIMITATIONS

What MOM knows and what it does not.

MOM can use
  • abdominal-sound recordings
  • the user's own hunger ratings
  • meal timing and optional context
  • saved preference choices
MOM does not know
  • an objective measure of hunger
  • thoughts or intentions
  • a diagnosis or medical condition
  • what nutrients a person medically needs
Guest privacy

Guest Mode shows no profile names, live sensor stream, private recordings, hunger history, saved food preferences, or personalized model outputs.

PRIVATE SENSOR DASHBOARD

The public site is always separate from private user data.

The public Guest website you are viewing is cloud-hosted on GitHub Pages and does not depend on the home Mac or sensor. The live private dashboard requires a running backend somewhere. The current prototype can run that backend on a Mac; the next infrastructure step is moving that private backend/database to a managed cloud host so it also stops depending on a particular computer.

Why the separation matters: I would rather show an accurate “private backend offline” state than pretend a local computer is an always-on cloud service.
For researchers and engineers: technical details
Hardware

ESP32 + MAX4466 microphone amplifier + stethoscope acoustic coupling. MAX4466 OUT connects to GPIO32 in the current prototype.

Signal features

Session summaries can include RMS, event measures, spectral centroid, bandwidth, entropy, band power, clipping, and movement/noise indicators.

Model comparison

Meal timing only, sound only, and a combined personal model are compared so the system can test whether sound appears to add useful information.

Uncertainty

Low-quality or immature cases can return “Not enough information.”
