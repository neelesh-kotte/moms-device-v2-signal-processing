# Independent operator evidence

## Recorded claim

Two independent people reproduced the physical recording workflow without direct supervision.

The public record intentionally identifies them only as anonymized operators. No names, health information, or private recordings are published here.

## What this result means

This is evidence that the written workflow was understandable enough for two people besides the designer to carry it out without live step-by-step supervision.

It is not a population reliability estimate. The sample is small, and the public summary does not claim that two successful reproductions establish universal operator agreement, clinical reproducibility, or device validity.

## Protocol context

The reproduced workflow used the same project setup:

- stethoscope-style acoustic coupling;
- MAX4466 microphone amplifier;
- ESP32 acquisition path;
- documented placement and recording instructions;
- the project’s signal-quality and completion checks.

The operators were not asked to produce a desired result. The relevant outcome was whether the documented recording workflow could be completed without direct supervision.

## Privacy and audit boundary

The public evidence package reports the aggregate result because publishing names, personal recordings, or health-related context is unnecessary for the engineering claim. If a future audit requires more detail, the appropriate record would be an anonymized operator log containing:

| Field | Purpose |
|---|---|
| Operator code | Keep identity separate from the public report |
| Protocol version | Identify the exact instructions used |
| Hardware configuration | Distinguish microphone/gain/mounting changes |
| Completion status | Show whether the workflow was completed |
| Quality-check output | Show what the system reported |
| Assistance level | Separate independent execution from direct coaching |
| Failure notes | Show where the written protocol needs revision |

No additional operator-level precision is asserted without that underlying log.
